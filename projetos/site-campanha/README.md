# Site de campanha

Site institucional de uma candidata a deputada estadual em Alagoas, nas eleições de 2026, com design próprio: apresentação, propostas, agenda e canais de contato, com botão de contato fixo no rodapé.

**[Ver no ar](https://walkiria22707.vercel.app/)**

## Como foi feito

- Página única, sem framework, com identidade visual da campanha e tipografia Inter.
- Metadados de compartilhamento (Open Graph), para que a prévia do link apareça bem em redes sociais e aplicativos de mensagem.
- Publicado na Vercel, com deploy automático a cada push na branch `main`.
- O código está na pasta `site-oficial/` do repositório [Website_Campanha](https://github.com/TjacksonAL/Website_Campanha), que também abriga o painel [Apura](../apura-painel-eleitoral/).

## Stack

HTML, CSS, Vercel.
